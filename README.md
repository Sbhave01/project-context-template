# {{PROJECT_NAME}} — shared project memory

Every person's Claude session on this project reads from and writes to this repo, so commercial,
product, marketing and dev all work from the same decisions and context.

**New here?** Read `SETUP.md` Part 2, then run `/start`.

| Command | When |
|---|---|
| `/start` | Beginning of a session — loads memory, briefs you |
| `/decide` | The moment something is agreed or approved |
| `/handoff` | End of every session — writes your session into shared memory |
| `/consolidate` | Monday — owner rebuilds `MEMORY.md` from the week's handoffs |
